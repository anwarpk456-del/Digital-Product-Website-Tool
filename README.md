# Digital-Product-Website-Tool

## Toolfinia

This repository contains the Toolfinia landing page as a static site in
`index.html`.

### Deploy on Vercel

1. Import `anwarpk456-del/Digital-Product-Website-Tool` in the Vercel dashboard.
2. Set the project name to `toolfinia`.
3. Use the **Other** framework preset, with no build command and the project
   root as the output directory.
4. Deploy. Vercel will also redeploy when changes are pushed to the connected
   GitHub branch.
